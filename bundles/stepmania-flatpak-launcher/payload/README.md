# StepMania Payload Notes

This payload directory is intentionally small. Keep generated songs, packs, and
large StepMania content outside the repository and copy known-good packs into
the staged `Songs/` directory during host smoke.

The Batocera bundle owns launch and lifecycle behavior only. Content generation,
chart writing, and OutFox/StepMania compatibility testing belong in the
StepMania content/tooling repo.
